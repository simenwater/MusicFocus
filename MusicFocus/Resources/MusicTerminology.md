## 使用说明 / Usage Notes

### 论文中应使用的术语 / Terms to use in paper:
- **HNR** (Harmonic-to-Noise Ratio) 而非"谐噪比"
- **Pitch Clarity** 而非"Pitch Detection Accuracy"
- **Spectral Stability** 而非"Spectrum Stability"
- **Focus Rate** 而非"Concentration Rate"

### 应用中的显示 / Display in app:
- **简体中文环境**: 显示中文术语
- **English environment**: Display English terms
- **保持一致性**: 确保同一术语在不同界面使用相同翻译
